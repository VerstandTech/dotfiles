# Canonical AI resources

`~/.agents` is the single source of truth for AI-agent resources managed by
this dotfiles repository.

## Layout

- `skills/` — portable capabilities following the [Agent Skills
  specification](https://agentskills.io/specification).
- `adapters/claude/` — Claude-specific global instructions and custom-agent
  definitions.
- `adapters/codex/` — Codex-specific instructions and command-approval rules.
- `adapters/pi/personal/` — the local Pi package (extensions, prompts, skills,
  subagents, tests, and supporting code).
- `scripts/` — deterministic validation for the canonical tree and deployed
  stow links.
- `manifest.json` — ownership, consumer, and discovery metadata.
- `.skill-lock.json` — provenance generated by the skill installer for skills
  it manages; it is not the complete resource inventory.

Vendor stow packages contain only native settings/instruction entrypoints and
symlink wiring. Codex, OpenCode, and Pi discover `~/.agents/skills` directly.
Grok uses its documented `[skills].paths` configuration so native Grok skills
remain available. The installer generates Claude's documented per-skill links
while preserving native/local entries under `~/.claude/skills`.

## Validate

```bash
python3 ~/.agents/scripts/test_verify_ai_resources.py
bash ~/.agents/scripts/test-install-ai-wiring.sh
python3 ~/.agents/scripts/verify-ai-resources.py \
  --repo ~/dotfiles \
  --home "$HOME"
```

The validator checks skill metadata, Claude agent frontmatter, Codex rule
safety, expected adapter ownership, symlink containment, and deployed links.
Run it after adding, moving, or removing an AI resource.
